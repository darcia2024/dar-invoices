01
Audit Keamanan Server & Penutupan Celah RCE Next.js 15.1.3 & React 19
Memperbaiki kerentanan kritis server yang memungkinkan eksekusi kode jarak jauh tanpa autentikasi, serta perapian kunci enkripsi:
  • Upgrade Dependensi Aman: Pembaruan versi Next.js dan React ke versi stabil yang telah menutup celah keamanan, disertai pengetesan menyeluruh agar alur checkout tidak terganggu.
  • Rotasi Kunci Enkripsi & Token: Mengganti seluruh kredensial Google OAuth, API key Mayar, dan password database, serta memindahkan penyimpanan ke environment server aman.
  • Security Headers Standar Industri: Penerapan konfigurasi CSP dan X-Frame-Options untuk mencegah clickjacking pada dashboard pengguna.
  • Mekanisme Arsip Kursus: Tombol hapus kursus diganti menjadi sistem arsip bertahap dengan konfirmasi, mencegah hilangnya data santri aktif berbayar.

Optimalisasi Alur Konversi Pendaftaran & Integrasi Payment Mayar
