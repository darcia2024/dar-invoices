Audit & Penanganan Tuntas 37 Masalah Sistem & Keamanan

Penutupan celah keamanan kritis server (upgrade Next.js 15.1.3 & React 19 untuk mencegah RCE), rotasi seluruh kredensial rahasia (OAuth, database, token gateway), security headers, pembukaan 6 tombol beranda langsung ke katalog publik tanpa mental ke login, pembenahan alur checkout Mayar real-time, perbaikan format teks materi kajian, dan dukungan penuh teks Arab kanan-ke-kiri (RTL) untuk matan kitab.

Patch Keamanan Server Katalog Publik & Silabus Mayar Gateway Sync Teks Arab Matan RTL
1. Keamanan & Server Mendesak (5 Butir)
Upgrade dependensi aman Next.js & React 19, rotasi kunci rahasia kompilasi, security headers (CSP & X-Frame-Options), proteksi penghapusan kursus aktif dengan sistem arsip bertahap, dan standarisasi pesan validasi form.
2. Konversi Pendaftaran & Pembayaran (7 Butir)
Pembukaan katalog publik, halaman detail silabus & preview video gratis, 4 halaman legal resmi (Kebijakan Privasi, Syarat, Refund, Kontak), sinkronisasi status pembayaran Mayar riil, proteksi webhook rate-limiting, dan peningkatan kontras teks.
3. Pengalaman Santri & Pengajar (4 Butir)
Restrukturisasi dashboard santri fokus lanjut belajar materi terakhir, perbaikan formatting paragraf & blok Arab RTL, modul urutan pelajaran & edit harga bagi pengajar, serta log audit hak akses admin.
4. Optimasi Belakang Layar & SEO (21 Butir)
Database query caching untuk halaman beranda instan, sanitasi embed video YouTube, sentralisasi middleware proteksi rute, halaman error 404/500 Bahasa Indonesia, OpenGraph metadata WhatsApp preview, favicon resmi, dan optimasi pemuatan font.
